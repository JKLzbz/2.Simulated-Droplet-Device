# 实现“近场/远场”动态打分体系的架构重构

## 背景目标
引入“理论推导-临床真实-机器模拟”三轴验证体系。根据红外传感器（VL53L1X）实时采集到的物理距离，动态切换打分评价体系，剥离此前的固定假打分映射代码，实现完全真实的数学物理对标。

## 方案设计

### 1. 距离区域划分
单片机实时回传 `distance`（单位为 mm）。我们设定界限阈值为 `400.0` (40cm)。
- **近场 (<= 400mm)**：采用数学方程对标（层流区）。
- **远场 (> 400mm)**：采用物理能量对标（湍流区）。

### 2. 近场：真实 FastDTW 形态学打分
- 当在近场触发打分时，剥离现有的 `score = 99.8 - ...` 硬编码映射。
- 采用真实的数学相似度映射函数：`True_Score = 100.0 * exp(- distance / 15000.0)`（或者结合欧式距离与余弦相似度联合打分），确保分数能真实反映出 0-100 的差异。
- **UI表现**：高亮显示 `DTW 相似度` 面板，显示如 `92.45% (近场高置信)`。

### 3. 远场：衰减积分与物理绝对对标
- 当在远场触发打分时，由于形态必然破碎，数学方程失效。
- **UI表现**：将 `DTW 相似度` 面板置灰，文字变为 `N/A (远场不适用)`。
- **UI联动**：高亮原有的 `达峰时间 (PVT)`、`原始振幅 (Amplitude / CPFR)`、`总能量积分 (AUC / CEV)` 面板。
- 用这三个离散物理量来证明远场飞沫的“存在性”与“破坏力”，替代波形拟合。
