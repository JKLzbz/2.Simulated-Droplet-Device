# Simulated Droplet Device (液滴形态学高频测控系统)

🏆 **第十九届中国研究生电子设计竞赛 (研电赛) 区域赛获奖项目**

## 📖 项目简介
本项目为一款基于边缘计算与高频电容检测的非接触式液滴测控系统。通过 FDC2214 传感器实时采集空间微电容变化，并采用 **STM32 + ESP32 双主控解耦架构** 保证系统在复杂工况下的极高稳定性。系统不仅包含了底层硬件驱动与 RTOS 任务调度，还配套了基于 Python 开发的跨平台上位机控制中心，实现数据的实时波形渲染与形态学分析。

## 🏗️ 系统架构
本项目为**全栈独立开发**，涵盖硬件底盘、网络链路与应用界面：
* **下位机核心 (STM32F407)**：负责硬核信号采集。运行 FreeRTOS 实时操作系统，驱动 FDC2214 进行极高精度的微电容数据获取，并完成初步的数据滤波与姿态解算。
* **通信分发网关 (ESP32)**：作为协同处理器，专职网络数据的分发。通过 UART 与 STM32 高速通信，解决单一 MCU 网络栈拥堵问题，将数据封装为 TCP/UDP 字节流穿透至上位机。
* **上位机监控中心 (Python)**：基于现代 GUI 框架搭建。提供实时动态波形监控界面，对底层传输的帧头字节流进行精准解包，并内嵌 FastDTW 算法对波形进行形态学评价。

## 💡 核心技术亮点
1. **双主控解耦设计**：创新性剥离“数据采集”与“网络传输”任务，做到物理级资源隔离，彻底避免了处理 TCP/IP 协议栈时可能导致的中断阻塞和死机。
2. **高频微小信号处理**：通过深入分析 I2C/SPI 时序，优化传感器底层驱动，实现对空间极微小电容波动的敏锐捕捉。
3. **精准字节对齐控制**：在跨语言（C 语言与 Python）通信中，完美解决结构体数据打包时遭遇的内存对齐（Byte Alignment）与大小端错位问题，实现稳定解析。
4. **实时形态学评价**：抛弃简单的绝对阈值判断，在远场引入实测波形作为动态参照，采用动态时间规整（DTW）算法实现跨维度的形态学分析。

## 📁 目录结构
- `01_Python_UI_Host Computer/`：上位机源码 (GUI、网络 Socket 监听、数据解析)
- `02_ESP32_Slave Computer/`：通信网关源码 (TCP Server、串行口数据转发)
- `03_STM32F407/`：核心下位机源码 (FreeRTOS 任务调度、FDC2214 驱动、数据滤波)
